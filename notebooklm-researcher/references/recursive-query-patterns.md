# 🔬 Recursive Query Patterns: 꼬리 질문 설계 패턴

> **목적**: Dive Mode에서 하나의 주제를 재귀적으로 심화하는 질문 패턴 모음.
> 끝없이 도는 무한 루프를 막으면서도, 정보의 뿌리에 도달할 때까지 집요하게 파고드는 전략.

---

## 1. Gap Detection Rules (정보 공백 탐지 규칙)

답변을 수신한 후, 아래 5가지 신호(Signal)를 탐지하여 후속 질문의 필요성을 판단합니다.

| # | 신호 | 탐지 기준 | 후속 질문 유형 |
| :--- | :--- | :--- | :--- |
| 1 | **불확실성 마커** | "~일 수 있다", "논쟁이 있다", "추가 연구 필요" | 구체적 근거 요청 |
| 2 | **미정의 전문 용어** | 새로운 개념이 설명 없이 등장 | 용어 해명 질문 |
| 3 | **단일 관점 편향** | 찬성 의견만 또는 반대 의견만 서술 | 반론 · 대안 질문 |
| 4 | **인과관계 불명** | "A 때문에 B"라고 하나 중간 논리가 부재 | 인과 경로 질문 |
| 5 | **출처 부재** | 주장에 Citation이 없음 | 출처 명시 요청 |

## 2. 질문 패턴 유형 (Question Pattern Types)

### Type A: 근거 추적 (Evidence Tracing)
```
"방금 언급된 '{주장}'의 구체적인 근거나 출처는 무엇인가?"
"'{개념}'이 처음 제안된 문헌이나 학자는 누구인가?"
```

### Type B: 반론 탐색 (Counter-Argument Search)
```
"'{주장}'에 대한 주요 반론이나 비판적 관점은 무엇인가?"
"'{학자A}'의 입장에 반대하는 대표적인 학자와 그 논거는?"
```

### Type C: 전제 해부 (Premise Dissection)
```
"'{결론}'이 도출되기 위해 전제되어야 하는 가정들은 무엇인가?"
"이 논증에서 숨겨진 전제(Hidden Premise)가 있는가?"
```

### Type D: 비교 대조 (Comparative Analysis)
```
"'{개념A}'와 '{개념B}'의 핵심적인 차이점과 공통점은?"
"동일한 문제를 해결하기 위한 대안적 접근법들은?"
```

### Type E: 실천적 함의 (Practical Implications)
```
"이 이론적 결론이 실제 '{분야}'에서 어떻게 적용되는가?"
"'{원리}'를 실무에 적용할 때 예상되는 장애물은?"
```

## 3. 탈출 조건 (Exit Conditions — Nash Equilibrium)

무한 루프를 방지하기 위해 아래 3가지 탈출 조건 중 **하나라도** 충족되면 즉시 종합 보고로 전환합니다.

| # | 조건 | 설명 |
| :--- | :--- | :--- |
| 1 | **소스 포화** | 3회 연속 동일한 소스(Source ID)만 인용됨 |
| 2 | **정보량 체감** | 직전 답변 대비 새로운 정보의 증분이 1~2문장 이하 |
| 3 | **최대 깊이 도달** | 최대 7회 반복 질문 (Hard Limit) |

## 4. 추론 경로 시각화 (Thought Chain Visualization)

Dive Mode 완료 시, 질문의 흐름을 아래와 같이 시각화하여 보고합니다.

```
Q1: "온톨로지의 정의는?" 
  └─ Q2: "온톨로지와 Taxonomy의 차이는?" [Gap: 미정의 용어]
       └─ Q3: "Taxonomy의 한계가 GraphRAG로 해결되는가?" [Gap: 인과 불명]
            └─ Q4: "GraphRAG의 구체적 구현 사례는?" [Gap: 출처 부재]
                 └─ ⛔ EXIT: 소스 포화 (3회 연속 동일 인용)
```
