# 📖 NotebookLM Researcher v3.0: User Guide

> **Version**: 3.0.0 (Third Gen)
> **Goal**: NotebookLM을 리서치 런타임으로 활용하여 자동화된 지식 습득 및 심층 연구 수행.

---

## 1. 🚀 스킬 가동 (Triggers)

다음 키워드를 포함하여 요청하면 에이전트가 즉시 리서치 모드로 진입합니다.
- **태그**: `#nlm`, `#소스루프`, `#리서치`
- **명령어**:
  - "NotebookLM 연구해줘"
  - "이 주제 전방위 파악해줘"
  - "리서치 플랜 짜줘"
  - "관련 자료 웹에서 더 찾아줘"

---

## 2. 🧩 3가지 연구 모드 (Research Modes)

에이전트는 사용자의 의도를 분석하여 아래 3가지 모드 중 최적의 방식을 선택합니다.

### ① ⚡ Plan Mode (사전 질문 설계)
- **용도**: 낯선 분야의 빠른 이해, 대량 자료의 다각도 요약.
- **동작**: AI가 6축(정의, 역사, 구조, 논쟁, 적용, 연결) 질문 세트를 사전 생성 후 일괄 질의.
- **예시**: "온톨로지 AI 에이전트에 대해 전반적으로 분석하고 강의 자료용 Q&A를 만들어줘."

### ② 🔬 Dive Mode (재귀적 심층 추론)
- **용도**: 특정 논점의 심층 탐구, 근거 추적, 학술적 배경 분석.
- **동작**: 답변 내 정보 공백(Gap)을 탐지하여 꼬리에 꼬리를 무는 질문(재귀) 수행.
- **예시**: "바르트의 성찬론 논쟁의 뿌리를 찾고, 반대 학자들의 논거를 끝까지 추적해줘."

### ③ 🌐 Scout Mode (외부 소스 발굴)
- **용도**: 정보 부족 시 외부 웹/드라이브 검색 및 소스 확장.
- **동작**: `research_start` 기능을 통해 새로운 문헌을 발굴하여 노트북에 자동 임포트.
- **예시**: "최근 AI 트렌드 리포트를 웹에서 더 찾아서 내 노트북에 추가하고 요약해줘."

---

## 🔄 3. 표준 워크플로우 (Workflow)

1.  **[INTAKE]**: 주제와 최종 목표(강의/논문/블로그 등) 수신.
2.  **[PLAN]**: 최적 모드 선택 및 질문 세트 설계 (Sequential Thinking 활용).
3.  **[EXECUTE]**: NotebookLM MCP 도구로 실제 리서치 수행.
4.  **[VERIFY]**: 답변 정밀도 및 인용(Citation) 누락 여부 검증.
5.  **[REPORT]**: `research-report-template.md` 포맷으로 최종 보고서 생성 및 아카이빙.

## 📝 4. 실전 명령 예시 (Quick Start)

| 상황 | 추천 명령 |
| :--- | :--- |
| **빠른 개요 파악** | "#nlm 이 주제에 대해 전방위 리서치 플랜 짜고 답변 요약해줘." |
| **심층 근거 추적** | "이 논쟁의 핵심 근거를 재귀적으로 깊게 파줘. 출처는 반드시 표기하고." |
| **자료 확장 및 연구** | "웹에서 관련 논문 더 찾아보고(Scout), 그 내용 포함해서 다시 정리해줘." |
| **단권화 리서치** | "이 노트북 소스 전체를 관통하는 지식 지도를 마크다운 보고서로 만들어줘." |

## 💡 Pro Tips

- **목표 명시**: "강의자료 제작용", "논문 석의용" 등 목표를 구체적으로 말하면 질문의 날카로움이 달라집니다.
- **Conversation ID**: 재귀 연구 시 대화의 맥락이 유지되므로 "방금 그 답변에서 이 부분을 더 자세히"라고 요청하면 효과적입니다.
- **인용 정규화**: 보고서의 모든 주장은 `[소스명][번호]` 형식으로 링크되므로, 원문 대조가 매우 쉽습니다.
