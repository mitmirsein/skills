# 🏗️ Remotion Studio: Gotchas & Anti-Patterns

Remotion 기반 비디오 제작 및 렌더링 시 에이전트가 주의해야 할 사항입니다.

## 1. Directing Pitfalls (디렉팅의 함정)
- **정보 과잉**: 한 화면에 너무 많은 텍스트를 넣지 마십시오. 쇼츠 영상의 핵심은 '간결함'과 '임팩트'입니다.
- **어색한 페이싱 (Pacing)**: 오디오의 읽기 속도와 자막/화면 전환 속도가 맞지 않으면 시청 흐름이 깨집니다. `video-config.json`의 지속시간(duration)을 정교하게 계산하십시오.

## 2. Asset Failures (애셋 실패)
- **TTS 기계음 만연**: `edge-tts` 사용 시 억양이나 끊어 읽기가 부자연스러운 부분이 있는지 확인하십시오. 마침표(.)나 쉼표(,)를 통해 자연스러운 호흡을 유도하십시오.
- **저해상도 리소스**: 4K 렌더링을 목표로 하면서 720p 이미지를 사용하는 실수를 방지하십시오.

## 3. Rendering Errors (렌더링 오류)
- **Node.js 버전 불일치**: Remotion 실행에 필요한 Node.js 버전과 패키지 의존성을 확인하십시오.
- **메모리 부족**: 복잡한 움직임이나 고화질 에셋이 많을 때 렌더링 서버의 메모리가 부족하여 중단될 수 있습니다. 렌더링 전 `dry-run`을 권장합니다.
- **Z-Index 혼선**: 자막이 배경 이미지 뒤로 숨거나, 로고가 텍스트를 가리는 레이어 우선순위 오류를 점검하십시오.
