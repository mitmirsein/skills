# Gotchas for #btw (Side-Quest Logic)

이 문서는 `#btw` 스킬 운용 중 발생할 수 있는 에러와 예외 상황을 예방하기 위한 사례집입니다.

### 1. 컨텍스트 승격(Promotion) 시점 오판 🚩
- **문제**: 사용자의 `#btw` 질문이 사실은 현재 작업 중인 코드의 치명적인 버그와 연관되어 있음에도, 휘발성으로만 처리하여 리더가 나중에 해당 정황을 잊어버림.
- **해결**: 질문에 "코드", "버그", "수정", "결정"과 같은 키워드가 포함될 경우, 반드시 "이 내용은 메인 작업에 기록될 필요가 있어 보입니다"라고 건계(Promote)를 수행할 것.

### 2. 지나치게 긴 요약문 (Session Pollution) 🌊
- **문제**: 클로드 코드 `/btw`의 목적은 '한 줄/짧은 답변'임에도, 에이전트가 평소 습관대로 1000토큰 이상의 긴 글을 작성하여 메인 세션을 오염시킴.
- **해결**: 강제적으로 답변 길이를 제한(Max 5-10 sentences). 더 자세한 정보는 `history.log` 혹은 별도 파일로 넘길 것을 제안.

### 3. 이전 BTW 기억 상실 🧠
- **문제**: 매번 `#btw` 호출 시 에이전트가 이전을 잊고 다시 초기화됨.
- **해결**: 동일한 세션 내에서는 `.skills/btw/history.log`를 읽어 이전 BTW 질문의 맥락을 살짝 참조할 것. (상세 내역은 `log-miner` 등과 연동 가능)

### 4. 도구 오동작
- **문제**: `#btw` 도중 메인 작업 중인 파일을 `write_to_file`로 건드림.
- **해결**: **절대 주의**. `#btw`는 '정찰'과 '답변'용이며, 메인 워크스페이스 파일을 수정하는 것은 반드시 리더의 명시적 허가를 받은 메인 태스크에서만 수행함.
