# eng-student-consultant (수학중독학원 영어과 통합 관리 도구)

## When to use this skill
사용자가 안티그래비티 대화창에 다음 두 가지 형태 중 하나를 요청했을 때 구동합니다.
1. **상담지 생성 요청**: "레벨테스트 상담지 만들어줘", "이영희 학생 리포트 뽑아줘" 등 (자연어 점수 입력 분석 및 옵시디언 마크다운/SVG 생성).
2. **웹 프로그램 구동 요청**: "학생 관리 프로그램 켜줘", "서버 구동해줘", "로컬호스트 띄워줘" 등 (Vite 개발 서버 구동).

---

## 🎯 세부 작동 프로토콜

### 1. 학생 관리 로컬 웹 서버 구동 시나리오 (localhost 실행)
사용자가 웹 화면에서 직접 입력하고 제어하길 원하여 **"웹 프로그램 실행해줘"** 또는 **"서버 켜줘"**라고 요청할 시 아래의 단계로 구동합니다.

*   **단계 1**: `projects/eng-student-manager` 디렉토리에 의존성 패키지(`node_modules`)가 설치되어 있는지 확인합니다. 만약 설치되어 있지 않다면 `npm install`을 먼저 수행합니다.
*   **단계 2**: `run_command` 도구를 사용해 Vite 개발 서버를 구동합니다.
    *   **Cwd**: `~/Desktop/MS_Dev.nosync/projects/eng-student-manager`
    *   **CommandLine**: `npm run dev`
    *   **WaitMsBeforeAsync**: `1000` (서버가 올라갈 수 있도록 비동기 백그라운드 태스크로 전환하기 전 대기)
*   **단계 3**: 서버 구동 메시지 출력 시, 로컬 주소인 [http://localhost:5173](http://localhost:5173) 링크를 대화창에 제공하여 강사가 브라우저에서 바로 클릭하여 실행할 수 있도록 안내합니다.
*   **단계 4**: 실행 중인 서버의 종료를 원할 시 안티그래비티의 `manage_task` 툴을 사용해 태스크를 `kill` 할 수 있음을 설명합니다.

---

### 2. 오프라인 상담지 생성 및 볼트 연동 시나리오
사용자가 대화창에서 원생의 레벨테스트 점수(어휘, 문법, 구문, 독해, 서술형)를 주며 분석을 요청할 때 작동합니다.

*   **단계 1**: 입력 정보(이름, 학년, 점수 5종, 추천 클래스/교재) 파싱.
*   **단계 2**: 에이전트(LLM)가 아래의 **[학업 평가 기준표]**를 엄격히 적용하여 학부모 지향적 톤앤매너로 고품질 1차 진단 소견서를 마크다운으로 편찬합니다.
*   **단계 3**: 파이썬 헬퍼 스크립트 `~/Desktop/MS_Dev.nosync/agents/student_consultant.py`를 실행하여 SVG 방사형 차트가 탑재된 문서를 프로젝트 내부 data/ 폴더에 저장합니다.
    ```bash
    python3 ~/Desktop/MS_Dev.nosync/agents/student_consultant.py \
      --name "[학생이름]" \
      --grade "[학년]" \
      --vocab [어휘점수] \
      --grammar [문법점수] \
      --syntax [구문점수] \
      --reading [독해점수] \
      --writing [서술형점수] \
      --recommended_class "[추천수강반]" \
      --recommended_books "[추천교재]" \
      --diagnosis "[단계 2에서 에이전트가 편찬한 진단 내용]"
    ```
*   **단계 4**: 생성된 결과 파일 경로 링크를 제공합니다 (예: [이영희_레벨테스트_상담지.md](file://~/Desktop/MS_Dev.nosync/projects/eng-student-manager/data/이영희_레벨테스트_상담지.md)).

## 📊 학업 평가 기준표 (진단 프롬프트용)
1. **어휘 (Vocabulary)**
   - 85점 이상: 학년 수준의 필수 어휘 및 심화 어휘 완성도가 높음. 고난도 수능 독해 어휘 및 동의어/반의어 정리 단계 진입 권장.
   - 60점~84점: 핵심 어휘는 인지하고 있으나 구동사나 다의어, 문맥상 알맞은 어휘 추론 능력이 다소 부족함. 매 수업 철저한 단어 테스트와 누적 암기 필요.
   - 60점 미만: 기초 어휘 결손이 심각하여 독해 및 어법 학습의 발목을 잡고 있음. 중등 기초 어휘부터 품사 구분 학습 병행 필수.
2. **문법 (Grammar)**
   - 80점 이상: 고등 내신 수준의 응용 어법 문제와 서술형 영작에 대한 대처 능력이 있음. 논리적 오류를 스스로 감지하고 수정 가능.
   - 50점~79점: 기본 어법 개념(형식, 관계사, 수동태 등)은 머리로 인지하고 있으나, 실제 문장 내 적용력 및 복합 어법 문제에서 오답률이 높음. 개념 구조화와 서술형 단원별 작문 연습 필요.
   - 50점 미만: 8품사, 기본 문장 형식, 시제 등 기초 뼈대 문법의 재정립이 시급함. 구조 분석 연습과 쉬운 구문 훈련 선행 필수.
3. **구문독해 (Syntax)**
   - 80점 이상: 복잡한 단문 및 장문의 구조 분석이 정교함. 도치, 분사구문, 삽입절 등이 포함된 킬러 문장도 올바르게 해석 가능.
   - 55점~79점: 단순 3형식 문장은 직독직해가 가능하나, 수식어가 붙거나 절이 길어지면 감에 의존한 '소설 독해' 경향을 보임. 구문 분석(주어/동사/수식어 끊어 읽기) 훈련 집중 배치 필요.
   - 55점 미만: 단어의 나열만으로 문장의 의미를 대충 때려 맞추는 상태. 문장 5형식 기초 뼈대를 잡고 짧은 문장부터 정확히 해석하는 연습 필수.
4. **논리독해 (Reading)**
   - 80점 이상: 글의 대의 파악 및 문맥 흐름을 잡는 논리 구조 판단력이 우수함. 빈칸 추론, 순서 배열 등 수능 형 고난도 문항 해결 가능.
   - 55점~79점: 주제 파악은 비교적 잘하나, 오답 매력도에 자주 빠짐. 지문 내 단서 찾기 훈련과 논리적 비약 방지 훈련 필요.
   - 55점 미만: 글을 읽고 전체 맥락이나 요지를 잡지 못함. 한글 번역본을 읽고도 이해하지 못하는 경우가 있어, 문장 간 연결 관계를 파악하는 기초 독해 훈련 요구됨.
5. **서술형 (Writing)**
   - 80점 이상: 한글 조건에 맞는 어법 배열 및 단어 변형 영작이 유려하며, 수일치나 시제 등의 세부 감점 요인이 거의 보이지 않는 탄탄한 영작 실력을 유지하고 있습니다.
   - 50점~79점: 기본적인 단어 나열은 가능하나, 전치사 사용 결손이나 수일치/시제 오류 등으로 인해 부분 감점이 빈번하게 발생하는 상태입니다. 내신 조건 충족 연습과 기출 서술형 빈출 패턴 훈련이 유효합니다.
   - 50점 미만: 기본적인 한글 구조를 영어의 어순으로 변환하는 영작이 불가능한 수준입니다. 필수 핵심 문형 50개의 문장 암기 및 어순 감각 배양부터 기초부터 단계를 밟아 올라가야 합니다.
