# Thoughtbox: Thinking Direction Router

문제의 유형에 따라 가장 효율적인 사고 경로를 선택하기 위한 가이드입니다.

| 문제 유형 | 추천 경로 | 특징 및 MCP 활용법 |
| :--- | :--- | :--- |
| **열린 탐색** | 순방향 (1→N) | 원인 불명, 브레인스토밍. 순차적으로 전개. |
| **목표 달성** | 역방향 (N→1) | 설계, 전략. 목표(N)에서 출발점(1)으로 역추적. |
| **대안 비교** | 분기 (Branch) | A vs B, 트레이드오프. `branchId`로 각 대안 탐색. |
| **오류 수정** | 수정 (Revision) | 디버깅, 검증. `isRevision=true`로 특정 단계 재고. |

## 🏗️ Backward Thinking Protocol (역방향 사고)
1. **Goal**: 최종 목표 상태를 정의합니다 (N).
2. **Pre-condition**: "이 목표가 성립하려면 바로 직전에 무엇이 참이어야 하는가?" (N-1).
3. **Execution**: 위 질문을 반복하여 현재 시점의 첫 번째 행동(1)에 도달합니다.
