# Thoughtbox: Token Economy & Best Practices

사고 과정의 효율성을 극대화하고 컨텍스트 낭비를 줄이기 위한 운영 지침입니다.

## 📉 Token Economy (컨텍스트 절약)
1. **Initial Scale**: `totalThoughts`는 3~5로 작게 시작하고 필요시 확장합니다.
2. **Brevidy**: 각 `thought` 단계는 3문장 이하로 요약하여 기술합니다.
3. **No Redundancy**: 이미 도출된 결론을 반복 설명하지 않습니다.

## 🧠 Logical Rigor (논리적 엄밀성)
- **Mental Models**: 복잡도가 아주 높을 경우에만 `view_file`을 통해 외부 프레임워크를 참조합니다.
- **Stop Condition**: 문제가 해결되었거나 더 이상의 정보 없이는 진전이 불가능할 경우 즉시 사고를 종료합니다.
- **Wait Policy**: 중간에 사용자 확인이 필요한 단계가 나타나면 사고를 멈추고 질문합니다.
