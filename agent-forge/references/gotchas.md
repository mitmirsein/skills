# 🏭 Agent Forge: Gotchas & Anti-Patterns

스킬을 설계·생성·최적화할 때 에이전트가 주의해야 할 함정입니다.

## 1. 생성의 함정 (Generation Pitfalls)
- **표준 미준수 생성**: 새 스킬은 반드시 `.skills/STANDARDS.md`(frontmatter 스키마,
  하이브리드 description, 150줄 상한, 경로 이식성)를 따른다. 생성 직후
  `python3 _meta/validate.py <skill>`로 A등급을 확인하지 않고 완료 선언 금지.
- **유령 참조 생성**: SKILL.md가 가리키는 references/scripts 파일을 실제로 만들지 않고
  링크만 쓰는 실수 — 본 라이브러리 최다 빈발 결함이다. 링크한 파일은 반드시 생성한다.
- **절대경로 하드코딩**: 예시 코드에 `/Users/<이름>/` 경로를 쓰지 않는다 (듀얼 맥 환경).

## 2. 최적화 루프의 함정 (Meta-Harness Pitfalls)
- **트레이스 없는 재작성**: 실제 실행 트레이스 없이 "더 좋아 보이는" 프롬프트로
  교체하는 것은 최적화가 아니라 회귀 위험이다. 반드시 실패 사례를 근거로 수정한다.
- **기존 버전 파괴**: 스킬 재작성 시 version 범프와 변경 요지 기록 없이 덮어쓰지 않는다.

## 3. 중복 스킬 양산 (Duplication)
- 새 스킬 생성 전 `INDEX.md`에서 동일 기능 스킬 존재 여부를 확인한다.
  유사 스킬이 있으면 신규 생성 대신 해당 스킬의 개선을 제안한다.
