신학 문서를 검색해주는 스킬을 만들어 보겠습니다.

## 스킬 개요

`theology-doc-search` — 사용자가 신학 주제나 키워드를 입력하면 관련 신학
문서·논문·1차 자료를 찾아 요약해주는 스킬입니다.

## 주요 기능

1. **쿼리 파싱**: 사용자의 자연어 질문에서 핵심 신학 키워드 추출
2. **검색 실행**: 웹/학술 DB에서 관련 문서 검색
3. **필터링**: 신뢰할 수 있는 신학 출처(학술지, 교부 문헌 등) 우선
4. **요약 반환**: 상위 결과를 출처와 함께 요약 제시

## SKILL.md 초안

```
이름: theology-doc-search
설명: 신학 주제를 검색하여 관련 문서를 찾아주는 스킬
사용법: 주제 입력 → 검색 → 요약 결과 반환
```

## 구현 시 고려사항

- 검색 소스의 신학적 신뢰도 평가 기준이 필요합니다.
- 1차 자료(성경·교부)와 2차 자료(현대 논문)를 구분하면 좋습니다.
- 결과에 출처를 반드시 명시하세요.

이 구조로 만들면 신학 문서 검색 기능을 제공할 수 있습니다. 검색 대상
소스(웹/특정 DB)나 출력 형식을 알려주시면 더 구체화하겠습니다.
