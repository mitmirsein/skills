## Phase 1: Architecting & Ops Design — 환경 스캔 (필수 선행)

`.skills/` 스캔 결과, **신학 문서 검색 기능이 이미 다수 존재**합니다:

| 기존 스킬 | 역할 | 중복도 |
|---|---|---|
| `theology-searcher` | 신학 문서/자료 검색 | **직접 중복** |
| `theology-scholar` | 학술 신학 검색·종합 | 높음 |
| `insane-search` | 범용·심층 검색 | 부분 |
| `google-scholar-semantic` / `semantic-scholar` | 학술 DB 검색 | 부분 |

→ **요청한 "신학 문서 검색 스킬"은 `theology-searcher`와 직접 중복**입니다.
agent-forge 원칙상 **중복 스킬을 무조건 신규 생성하지 않습니다**(스킬 난립은
트리거 충돌·유지보수 부채를 유발). 먼저 다음을 **확인**합니다.

## 권고: 신규 생성 대신 3택 (사용자 확인 필요)

1. **기존 `theology-searcher` 확장(extend)** — 부족한 기능만 보강.
   현재 갭이 무엇인지 알려주시면 해당 스킬을 패치합니다 (권장).
2. **차별화된 신규 스킬** — 기존과 *경계 조건이 명확히 다른* 경우에만.
   예: "전문(全文) 색인 기반 사내 PDF 검색" vs 기존 "웹/학술 검색".
   이때 description에 경계 조건을 명시해 트리거 충돌을 방지합니다.
3. **그대로 진행** — 중복을 감수하고 신규 생성(비권장, 사유 기록).

### 질문 (Question Policy: 최대 3문항)
```
1. 기존 theology-searcher 대비 무엇이 부족한가?
   A) 검색 소스 범위    B) 출력 형식/정밀도    C) 속도/캐싱    D) 신규 도메인
2. 처리 방식은?
   A) 기존 스킬 확장(권장)   B) 경계 분리한 신규   C) 중복 감수 신규
3. (B 선택 시) 기존과의 경계 조건은?
```

확인 전까지 **신규 파일을 생성하지 않습니다**. (Phase 2 보류)
