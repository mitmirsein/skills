> 실행일: 2026-05-18 · 실행자: Claude (agent-forge 비활성, 일반 응답)

---

여러 신학자 관점으로 본문을 분석하는 협업 스킬을 설계하겠습니다.

## 스킬 개요

`theologian-roundtable` — 한 성서 본문을 입력하면 역사비평, 조직신학,
목회적 적용 세 가지 시각에서 분석한 결과를 제공하는 스킬입니다.

## 작동 흐름

1. 사용자가 분석할 본문(예: 로마서 8:28)을 입력
2. 역사비평 관점 분석: 본문의 역사적 배경, 본문비평, 양식 분석
3. 조직신학 관점 분석: 교리적 함의, 신학 체계 내 위치
4. 목회적 적용 관점 분석: 오늘날 신앙 생활에의 적용
5. 세 분석을 하나의 보고서로 정리하여 반환

## SKILL.md 초안

```
이름: theologian-roundtable
설명: 한 본문을 세 가지 신학 관점으로 분석하는 스킬
사용법: 본문 입력 → 3관점 분석 → 종합 보고서
```

## 구현 팁

- 각 관점별로 출력 섹션을 명확히 구분하면 가독성이 좋습니다.
- 세 분석이 서로 모순될 경우 어떤 입장을 취할지 사용자에게 물어보면 됩니다.
- 각 관점의 분석 깊이를 일정하게 유지하세요.

이렇게 하면 한 본문에 대한 다각적 신학 분석을 제공할 수 있습니다.
관점을 추가하거나 특정 신학 전통(개혁신학 등)에 맞추고 싶으면 알려주세요.
