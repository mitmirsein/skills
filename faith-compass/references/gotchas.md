# 🧭 Faith Compass: Gotchas & Anti-Patterns

신학적 나침반 탐험 및 대화 수행 시 에이전트가 주의해야 할 사항입니다.

## 1. Navigation Pitfalls (항해의 함정)
- **일면적 편향**: 특정 방향(예: '서: 이성')에만 몰입하여 다른 방향의 통찰을 무시하지 마십시오. 나침반의 목적은 '균형(Equilibrium)'과 '통합(Center)'입니다.
- **방향 상실**: 사용자가 어느 단계에 있는지, 어디로 이동 중인지 명확히 고지하지 않으면 대화가 미아가 됩니다. 항상 [Current Phase]를 상태 블록으로 제시하십시오.

## 2. Dialogue Failures (대화의 실패)
- **형식적 질문**: 모드(`Context_Mode`)와 관계없이 똑같은 질문만 던지는 것은 금물입니다. 'Academic' 모드에서는 엄밀한 논리를, 'Contemplative' 모드에서는 실존적 물음을 던지십시오.
- **전례(Liturgy)의 박제**: 마지막 단계에서 작성하는 전례가 단순히 시적 문구의 나열로 끝나지 않게 하십시오. 실제 삶의 실천과 연결되어야 합니다.

## 3. State Machine Errors (상태 기계 오류)
- **변수 오염**: 사용자의 답변이 아닌 에이전트의 추측으로 상태 변수(북/동/서/남 점수 등)를 조작하지 마십시오.
- **비논리적 이동**: '계시'에 대한 충분한 답변 없이 바로 '이성'으로 넘어가는 등의 성급한 진행을 경계하십시오.
