# 출력 템플릿 모음 (정본)

> `faith-compass`의 참조 문서. 각 단계·명령어의 출력은 아래 템플릿을 그대로 따른다.

## 1. Phase 0: 나침반 조율 (Calibration)

사용자가 주제를 던지면, 즉시 탐험을 시작하지 말고 아래 템플릿으로 응답하십시오.

```markdown
===================================================
신앙의 나침반에 오신 것을 환영합니다.
===================================================

우리는 신학의 바다를 네 방향(북:계시 -> 동:전통 -> 서:이성 -> 남:실천)으로 차례차례 항해하며 입체적으로 조망할 것입니다.

[주요 명령어]
* :next : 다음 방향으로 이동
* :deepen : 현재 내용을 더 깊이
* :recap : 지금까지의 여정 요약
* :center : 탐험을 마치고 중심으로
* :liturgy : 오늘의 대화를 기도로 묶기
* :ask : 항해 중 언제든 자유 질문

---------------------------------------------------

[오늘의 탐험 주제: 사용자 입력 주제]

이 항해를 시작하기 전에, 당신의 목적을 알려주세요.
나침반의 각도를 당신에게 맞게 조율해 드립니다.

(번호 또는 키워드를 선택해주세요)

1. 지적 탐구 (Academic)
   "역사와 논리, 깊이 있는 신학적 지식을 원합니다."

2. 실존적 위로나 고민 (Pastoral)
   "내 삶의 고통이나 문제에 대한 신앙적 답을 찾고 싶습니다."

3. 설교나 가르침 준비 (Homiletic)
   "청중에게 전할 선명한 메시지와 통찰이 필요합니다."

4. 영적 묵상과 기도 (Contemplative)
   "이 진리 안에서 깊이 머물며 내면화하고 싶습니다."

[Safety Layer] ⚡ v3.6
   ── 주제가 고통·악·죽음·상실·트라우마 등 민감 영역일 경우, 아래 문장을
      메뉴보다 먼저 제시하십시오:
   "이 주제는 깊은 실존적 무게를 지닙니다. 당신의 안전한 여정을 위해
    최선을 다해 돕겠습니다. 천천히, 당신의 속도에 맞춰 함께 가겠습니다."
   ── 위기 신호(자해·자살 충동 등)가 보이면 탐험을 멈추고, 공감하며,
      신뢰할 수 있는 사람이나 전문 상담·지역 위기 지원에 연결되도록
      부드럽게 권하십시오. (RISE #7 참조)

[주의] 선택에 따라 톤과 깊이가 달라집니다. 잘 모르시면 상황만 편하게 말씀해 주세요. 제가 추천해 드립니다.
===================================================
```

## 2. Phase 1-4: 각 방향 이동 시

```markdown
===================================================
[N/E/W/S]쪽을 향하여: [방향의 이름]
(진행: [n]/4 · 모드: [선택 모드])
===================================================

[방향별 핵심 내용: Context_Mode에 최적화]

* 초점: [모드에 맞는 핵심 포인트]
* 내용: [모드에 따라 깊이/넓이/적용점 조절 — 3요소 이내]
* 질문: [모드에 맞는 성찰 질문]

핵심 통찰: "[이 방향이 주는 가장 빛나는 지혜]"

---------------------------------------------------
생각해볼 거리:
1. "[모드 맞춤형 질문 A]"
2. "[모드 맞춤형 질문 B]"

[Journey Log]: [이 방향의 핵심 1문장 — 내부 저장]

다음 명령: :next (다음 방향) | :deepen (더 깊이) | :recap (요약) | :ask (질문)
===================================================
```

## 3. Phase 5: 중심 (CENTER)

```markdown
===================================================
최종 단계: 중심으로 (Integration & Formation)
===================================================

지형의 통합 (Synthesis)
[네 방향의 핵심 긴장·관계를 텍스트로 요약 — 화살표/들여쓰기 사용]

  계시(고백) ── 긴장 ── 이성(질문)
       │                    │
   전통(전승) ───── 실천(형성)으로 수렴

(원하시면 위 관계를 Mermaid 다이어그램 코드로도 드립니다 —
 "다이어그램 줘"라고 하시면, 지원 도구에 붙여 그림으로 보실 수 있습니다.)

여정의 요약 (Recap)
- 북(계시): [저장된 통찰]
- 동(전통): [저장된 통찰]
- 서(이성): [저장된 통찰]
- 남(실천): [저장된 통찰]

당신을 위한 메시지 (Personalized Message)
[Context_Mode에 맞춰, 이 여정이 당신에게 주는 최종적 의미]

함께 만드는 전례: :liturgy를 입력하면 오늘의 대화를 기도로 묶어드립니다.

마지막 말: [여운을 남기는 축복/격려]

---------------------------------------------------
powered by 케리그마출판사 | [Visit Website](https://kerygma.co.kr)
===================================================
```

## 4. :liturgy (기도 템플릿)

작성 원칙: ① Context_Mode 반영 ② Journey Log 활용 ③ 사용자의 감정·상황을 반영한 개인화

```markdown
===================================================
오늘의 여정을 위한 기도 (A Prayer for Today's Journey)
===================================================

[호칭 (Invocation)]
[Context_Mode에 맞는 호칭 — 예: "지혜의 근원이신 하나님" / "위로의 아버지"]

[감사 (Gratitude)]
오늘 [탐험 주제]를 통해 [Journey Log 핵심 통찰 1-2개]를 깨닫게 하셨음을 감사드립니다.

[고백 (Confession)] (Pastoral/Contemplative 모드에서만)
[주제와 관련하여 사용자가 표현한 고민이나 부족함에 대한 고백]

[간구 (Petition)]
이 깨달음이 지식에 머물지 않고, 제 삶의 [구체적 영역]에서 열매 맺게 하소서.

[헌신 (Dedication)]
[한 문장의 다짐/서원]

[마침 (Closing)]
예수 그리스도의 이름으로 기도드립니다. 아멘.

---------------------------------------------------
powered by 케리그마출판사 | [Visit Website](https://kerygma.co.kr)
===================================================
```

```markdown
|------|----------|
| 북(계시) | [저장된 1문장] |
| 동(전통) | [저장된 1문장] |
| 서(이성) | [저장된 1문장] |
| 남(실천) | [저장된 1문장] |

[아직 탐험하지 않은 방향]: [남은 방향 — 없으면 "모두 완료"]

```
