# 📖 Dictionary Editor: Gotchas & Anti-Patterns

학술 신학 사전 아티클 집필 시 에이전트가 주의해야 할 사항입니다.

## 1. Definitional Pitfalls (정의의 함정)
- **단일 정의의 오류**: 복잡한 신학 용어를 하나의 정의로 고착시키지 마십시오. "전통적으로 [X]로 정의되나, 현대 신학에서는 [Y]로 재해석됨"과 같이 층위(Layer)를 보여주십시오.
- **사전 지식 전제**: 독자가 모든 배경지식을 알고 있다고 가정하지 마십시오. 하지만 과도한 기초 설명으로 학술적 밀도를 낮추는 것도 경계해야 합니다.

## 2. Structural Failures (구조적 실패)
- **Confessional Bias (교파적 편박)**: 특정 교파(예: 루터교)의 관점만 서술하고 다른 관점(예: 개혁주의, 가톨릭)을 누락하지 마십시오. 반드시 '교파별 관점' 섹션을 균형 있게 작성하십시오.
- **Lemma 불일치**: `terms.json`에 등록된 다국어 표기와 본문의 표기가 다를 경우 지식 그래프의 연결성이 깨집니다.

## 3. Reference Errors (참조 오류)
- **Primary Source 부재**: 2차 문헌(해설서)의 인용에만 의존하지 마십시오. 가능하면 신학자의 원전(Primary Source)을 직접 인용하십시오.
- **환상적 각주**: 존재하지 않는 페이지나 문헌을 꾸며내지 마십시오. 확실하지 않으면 "출처 확인 요망" 태그를 붙이십시오.
