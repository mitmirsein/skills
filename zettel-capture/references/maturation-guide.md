# 🌱 Maturation Guide (성숙 큐 운영 가이드)

제텔카스텐의 실전 병목은 "카드 작성"이 아니라 "다시 돌아가서 정리하는 것"입니다. 이 가이드는 미성숙 카드의 리뷰 및 승격 프로세스를 정의합니다.

---

## 1. 성숙도 단계

| 단계 | 아이콘 | 의미 | 조건 |
|:---|:---|:---|:---|
| **씨앗** | 🌱 | 신규 포착, 미가공 | 기본값 (모든 신규 카드) |
| **성장** | 🌿 | 출처 보강, 사유 심화 완료 | 출처 완비 + 사유 1문단 이상 |
| **완성** | 🌳 | 독립적 지식 단위, 재사용 가능 | 출처 독립 + Connection 1개 이상 |

---

## 2. `/zettel review` 명령어 실행 절차

대장이 `/zettel review`를 호출하면 다음 순서로 실행합니다.

### Step 1: 미성숙 카드 스캔
`config.json`의 `zettel_dir` 경로에서 `maturity: "🌱"` 또는 `maturity: "🌿"`인 카드를 수집합니다.

### Step 2: 리뷰 대시보드 출력
```
📊 Zettel Review Dashboard
━━━━━━━━━━━━━━━━━━━━━━━━━
🌱 씨앗 (미성숙): 12장
🌿 성장 (진행 중): 5장
🌳 완성 (재사용 가능): 23장
━━━━━━━━━━━━━━━━━━━━━━━━━
⚠️ 30일 이상 🌱 방치: 3장 (조속한 리뷰 권장)
```

### Step 3: 승격 후보 제시
가장 오래된 🌱 카드부터 순서대로 제시하며, 승격 가능 여부를 판단합니다.

```
📝 [20260301-002] "신적 자유와 자의의 구분" (💭 Fleeting, 🌱 24일 경과)
   → 출처 보강 필요: title만 있고 author/locator 누락
   → 사유 미기입
   → 권장: 📖 Literature로 전환 후 사유 기입
```

### Step 4: 대장 결정
대장이 각 카드에 대해 다음 중 하나를 지시합니다:
- **승격**: 🌱→🌿 또는 🌿→🌳 (누락 정보 보강 후)
- **유지**: 현재 상태 유지
- **폐기**: 더 이상 가치 없는 카드 삭제
- **병합**: 다른 카드와 통합

---

## 3. 승격 기준 상세

### 🌱 → 🌿 (씨앗 → 성장)
| 조건 | 필수/권장 |
|:---|:---|
| Source 메타데이터에 최소 `title` + `author` 또는 `url` 존재 | **필수** |
| Zettel(사유) 섹션에 1문단(3문장) 이상 기입 | **필수** |
| 노트 유형(type)이 확정 | **필수** |
| 태그 1개 이상 부여 | 권장 |

### 🌿 → 🌳 (성장 → 완성)
| 조건 | 필수/권장 |
|:---|:---|
| 원본 출처 없이도 독립적으로 의미 전달 가능 | **필수** |
| Connections에 최소 1개의 `[[wikilink]]` 존재 | **필수** |
| 💎 Permanent 유형으로 전환 | **필수** |
| Thesis(명제) 섹션이 하나의 명확한 주장을 담고 있음 | **필수** |
| Argument(논증) 섹션에 근거 제시 | 권장 |

---

## 4. `/zettel stats` 명령어 실행 절차

대장이 `/zettel stats`를 호출하면 다음 통계를 출력합니다:

```
📊 Zettel Statistics
━━━━━━━━━━━━━━━━━━━━━━━━━
유형별:
  💭 Fleeting:   8장 (20%)
  📖 Literature: 25장 (62.5%)
  💎 Permanent:  7장 (17.5%)

성숙도별:
  🌱 씨앗:  12장 (30%)
  🌿 성장:   5장 (12.5%)
  🌳 완성:  23장 (57.5%)

최근 7일 생성: 4장
30일 이상 🌱 방치: 3장
가장 많은 태그: #신론 (7회), #바르트 (5회), #자유 (4회)
━━━━━━━━━━━━━━━━━━━━━━━━━
```

## 5. 리뷰 주기 권장사항

| 주기 | 활동 | 소요 시간 |
|:---|:---|:---|
| **주 1회** | 🌱 카드 빠른 스캔, 즉시 승격/폐기 가능한 것 처리 | 10-15분 |
| **월 1회** | 전체 카드 현황 점검, 🌿→🌳 승격 심사, Connection 확장 | 30-60분 |
| **분기 1회** | Permanent Note 네트워크 전체 리뷰, 누락된 연결 발굴 | 1-2시간 |
