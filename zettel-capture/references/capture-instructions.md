# 📥 Capture Instructions (입력 유형별 처리 로직)

`zettel-capture` 스킬의 핵심 실행 로직입니다. 다양한 입력 유형에 대한 처리 규칙을 정의합니다.

---

## 1. 입력 유형별 처리

### A. 텍스트 직접 입력 (가장 흔한 경우)
대장이 문장이나 생각을 직접 타이핑한 경우.

```
대장: "바르트가 KD II/1 346쪽에서 '하나님의 자유는 자의가 아니다'라고 했는데, 이건 신적 결정론 비판에 쓸 수 있겠다. 메모해줘."
```

**처리 순서:**
1. Quote와 Zettel(사유)을 분리합니다.
   - Quote: "하나님의 자유는 자의가 아니다"
   - Zettel: "이건 신적 결정론 비판에 쓸 수 있겠다"
2. Source 메타데이터를 구조화합니다.
   - title: "교회교의학 II/1", author: "Karl Barth", locator: "p.346"
3. 유형을 📖 Literature로 판별하여 제안합니다.
4. 대장 승인 후 카드를 생성합니다.

### B. URL 입력
대장이 웹 페이지나 유튜브 URL을 함께 제공한 경우.

```
대장: "https://example.com/article 이 글에서 흥미로운 부분이 있었어. 메모해줘."
```

**처리 순서:**
1. URL의 제목과 저자를 가능한 한 자동 추출합니다 (메타 태그 활용).
2. 대장이 특정 문장을 지정했다면 그것을 Quote로 사용합니다.
3. 대장이 문장을 지정하지 않았다면, "어떤 부분이 인상적이었습니까?"라고 한 번만 질문합니다.
4. `source.url` 필드에 URL을 기록합니다.

**주의**: 이 스킬은 웹 스크래핑을 하지 않습니다. URL에서 전체 내용을 추출·요약하는 것은 `knowledge-archivist`의 영역입니다. 이 스킬은 대장이 지정한 특정 문장/인사이트만 포착합니다.

### C. 파일 경로 입력
대장이 로컬 파일의 특정 부분을 지정한 경우.

```
대장: "[[KD II-1 신론]] 노트에서 346쪽 인용구를 카드로 만들어줘."
```

**처리 순서:**
1. 해당 파일을 읽어 지정된 부분을 확인합니다.
2. Quote와 Source를 자동 구조화합니다.
3. 대장에게 사유(Zettel) 기입을 요청합니다 (사유 촉발이 ON인 경우에만).

### D. 자유 사유 (출처 없음)
대장이 특정 출처 없이 자신의 생각만 던진 경우.

```
대장: "트라우마 내러티브와 구원 서사의 구조적 유사성에 대해 더 생각해봐야겠다."
```

**처리 순서:**
1. 출처가 없으므로 💭 Fleeting으로 분류합니다.
2. Source 메타데이터는 비워둡니다.
3. 즉시 저장합니다 (추가 질문 없이 30초 이내 완료 목표).

## 2. Source 메타데이터 구조화 규칙

| 소스 유형 | title | author | locator | url |
|:---|:---|:---|:---|:---|
| **도서** | 책 제목 | 저자 | p.XXX | — |
| **논문** | 논문 제목 | 저자 | §X.X 또는 p.XXX | DOI/URL |
| **유튜브** | 영상 제목 | 채널명 | MM:SS | URL |
| **웹 페이지** | 페이지 제목 | 저자/사이트명 | — | URL |
| **팟캐스트** | 에피소드 제목 | 호스트/게스트 | MM:SS | URL |
| **강의/세미나** | 강의 제목 | 강사 | 날짜/세션 | — |
| **대화/설교** | 주제 | 화자 | 날짜 | — |

**원칙**: 모든 Source 필드를 억지로 채우지 마십시오. 대장이 제공한 정보만으로 구성하되, `title`이 최소한 존재해야 합니다. 없다면 물어보십시오.

---

## 3. 사유 촉발(Prompting) 규칙

| 상황 | 에이전트 행동 |
|:---|:---|
| 대장이 Quote + Zettel 모두 제공 | 즉시 카드 생성 (질문 없음) |
| 대장이 Quote만 제공 + config에서 prompting=ON | "이 문장에 대한 사유를 덧붙이시겠습니까?" 한 번만 질문 |
| 대장이 Quote만 제공 + config에서 prompting=OFF | Quote만으로 카드 생성 (Zettel 섹션 비워둠, maturity=🌱) |
| 대장이 "일단 적어놔" 등 즉시 저장 의사 표시 | 💭 Fleeting으로 즉시 저장 (어떤 질문도 금지) |

---

## 4. Connection 제안 규칙

카드 생성 시 에이전트는 다음 순서로 관련 연결을 **제안**합니다 (강제 아님):

1. **태그 기반**: 동일 태그를 가진 기존 카드가 있다면 `[[wikilink]]`로 제안.
2. **저자 기반**: 같은 저자의 다른 카드가 있다면 제안.
3. **주제 기반**: 의미적으로 관련된 기존 노트가 있다면 제안.

**제안 상한**: 최대 3개까지만. 너무 많은 링크를 제안하면 소음이 됩니다.
