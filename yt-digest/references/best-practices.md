# YT-Digest Best Practices & Tips

## 1. Agent Guidelines
- **Language Priority**: Default to Korean (`ko`) unless specified.
- **Transparency**: Mention if the transcript was "Auto-generated" (may contain inaccuracies) or "Manually uploaded".
- **Context Preservation**: Always keep the original URL and title in the metadata of the summarized document.

## 2. Maintenance
- **yt-dlp Updates**: Keep `yt-dlp` updated to avoid breaking changes in YouTube's API.
- **Timestamp Mapping**: If possible, map key sections back to timestamps for the user to facilitate verification.

## 3. Synergy
- **theology-writer**: Extracts can be directly used as citations in SBL formatted papers.
- **rise-exegesis-sermon**: Ideal for analyzing deep theological claims in sermons.
