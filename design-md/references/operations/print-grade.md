# 동사: print-grade — 인쇄급 에디토리얼 조판

창발: ui-skills 생태계에 없는 영역. 이 볼트의 설교·Kerygma 저널·학술 노트를 **인쇄물 수준**으로 조판한다. 화면 CSS와 별개로 페이지 매체를 다룬다.

## 페이지 셋업
- `@page { size: A4; margin: 25mm 22mm; }` — 본문 측정폭 확보용 여백.
- 좌우 페이지 구분 필요 시 `@page :left/:right`로 안쪽 여백을 넓혀 제본 영역 확보.
- 머리말/꼬리말: `@page` 마진박스 또는 러닝 헤더(장 제목·페이지 번호).

## 문단·금칙 (한글 인쇄)
- 고아줄/과부줄 방지: `orphans: 2; widows: 2;`
- 제목 직후 분리 방지: 제목에 `break-after: avoid;`, 표·그림 캡션과 함께 묶기.
- 한글 금칙처리: 줄 끝 여는 괄호·줄 머리 닫는 괄호/마침표 방지(`word-break: keep-all` + 필요 시 `line-break: strict`).
- 양쪽 정렬을 쓸 경우만 하이픈(`hyphens`)·자간 미세 조정. 한글 본문은 좌측 정렬 기본 권장(typeset).

## 에디토리얼 요소
- **본문**: Noto Serif KR / KoPubBatang, 11–11.5pt, 행간 1.6–1.75, 들여쓰기 1em 또는 단락 간격 중 하나로 일관.
- **성구·인용 블록**: 좌여백 들여쓰기 + 약간 작은 급수 + 출처 우측 정렬. 인용 안에서 강조는 이탤릭 절제.
- **각주/미주**: `counter` 기반 번호, 본문 위첨자 + 페이지 하단 영역. 각주는 본문보다 1–1.5pt 작게.
- **장/절 위계**: 제목 Serif bold, 절은 자간·급수로 구분. 챕터 첫 단락 들여쓰기 생략(인쇄 관습).
- 페이지 넘김: 장 시작은 `break-before: page;`.

## 색·잉크
- 인쇄는 흑백/단색 가정 가능 — 색만으로 위계 만들지 말 것(농담·급수·굵기로도 구분).
- 색 사용 시 OKLCH 토큰의 명도 사다리가 흑백 변환에서도 구분되는지 확인.

## 함정
- 화면용 그림자·그라데이션을 인쇄에 그대로 → 회색 떡짐. 인쇄 스타일시트에서 제거.
- 의미 평탄화 주의(gotchas §7): 대조되는 신학적 입장은 병렬 단/대조 블록으로 인쇄에서도 대등하게.
