# 동사: layout — 그리드·리듬·여백·위계

공간을 잡는 단계. 위계와 리듬이 무너지면 어떤 색·폰트도 살리지 못한다.

## 규칙
- **8px Base Grid**: 모든 간격·크기를 8의 배수(보조로 4)로. 임의의 `13px`, `27px` 금지.
- **간격 토큰화**: `--space-1:4px … --space-6:48px`처럼 스케일로 정의하고 토큰만 사용.
- **수직 리듬**: 섹션 간격 > 블록 간격 > 요소 간격 으로 *명확한 단계*를 둔다(예 64 / 24 / 8).
- **컨테이너 패딩**: 카드·섹션 내부 최소 24px, 페이지 좌우 거터는 뷰포트별로(모바일 16, 데스크톱 32+).
- **측정폭(measure)**: 본문 컬럼 45–75자. 풀폭 장문 금지.
- **위계**: 한 화면에 1차 행동(primary) 1개만 시각적으로 가장 강하게. 나머지는 secondary/tertiary로 강등.
- **정렬**: 광학 정렬(optical) 우선. 아이콘+텍스트는 baseline/center 일관.

## 레이아웃 패턴
- 콘텐츠는 `max-width` + 중앙 정렬, 그 안에서 grid/flex. 풀블리드는 의도적 강조에만.
- 비대칭 균형(asymmetry) 활용 — 모든 것을 가운데 정렬하면 양산형 룩이 된다.
- `gap`을 쓰고 마진 충돌(collapsing margin)에 의존하지 않는다.

## 함정
- 카드 그림자만으로 위계를 만들려 하지 말 것 — 간격·크기·위치가 먼저.
- 그리드 없이 눈대중 배치 → critique의 "리듬" 항목에서 감점.
