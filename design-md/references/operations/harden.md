# 동사: harden — 깨지지 않는 인터페이스

해피패스만 그린 UI는 절반만 완성된 것이다. 실데이터·실언어·실상태에서 무너지지 않게 한다.

## 반드시 설계할 상태
- **Empty**: 데이터 0건일 때의 화면(설명 + 다음 행동 유도). 빈 표/빈 카드 방치 금지.
- **Loading**: 스켈레톤 또는 명시적 인디케이터. 레이아웃 점프(CLS) 방지 — 자리 미리 확보.
- **Error**: 무엇이·왜 실패했고 사용자가 무엇을 할지. 재시도 경로 제공.
- **Partial / Long**: 아주 긴 제목·이름·URL에서 줄바꿈/말줄임(`text-overflow`, `min-width:0`, `overflow-wrap`).

## 한국어·다국어 견고성 (창발: 워크스페이스 특화)
- 한글은 영문보다 폭이 넓다 — 버튼·탭 레이블이 길어져도 안 깨지게 `min-width`/줄바꿈 허용.
- `word-break: keep-all`이 좁은 컨테이너에서 오버플로 유발할 수 있으니 `overflow-wrap: anywhere` 병행 고려.
- 숫자/날짜/통화는 로캘 포맷. 혼합 텍스트(한+영+숫자) baseline 정렬 확인.
- i18n 시 텍스트 길이 30% 팽창 가정. 하드코딩 폭 금지.

## 엣지·견고성
- 이미지 깨짐 대비 `alt` + 배경/플레이스홀더.
- 0/1/다수 복수형, 음수·초대형 수치, 미래/과거 날짜 표시.
- 포커스 트랩(모달), ESC 닫기, 스크롤 잠금 — 접근성과 함께.

## 함정
- 데모 데이터(짧고 예쁜 값)로만 검수 → 실데이터에서 레이아웃 붕괴.
- empty/error를 "나중에"로 미루면 critique의 harden 항목에서 큰 감점.
