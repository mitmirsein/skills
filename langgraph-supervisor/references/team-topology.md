# LangGraph Supervisor: Team Topology & Roles

복잡한 프로젝트를 수행하기 위한 Supervisor-Worker 위계 구조의 전문 역할 정의입니다.

## 👑 Supervisor (The Boss)
- **Responsibility**: 프로젝트 계획 수립, 작업 분해, 결과물 검수(Critic), 사용자 승인 획득.
- **Goal**: 팀의 전체적인 컨텍스트를 유지하고 작업의 흐름을 조율함.

## 🛠️ Specialized Workers (The Hands)

1. **OCR Specialist**: 고서/이미지에서 텍스트와 레이아웃 구조를 추출.
2. **Sanitizer**: 텍스트의 오타, 노이즈, 인코딩 오류를 정제(Cleaning).
3. **Theologian**: 신학적 맥락과 전문 용어를 반영하여 학술적 번역/분석 수행.
4. **Draft Editor**: 개별 작업물의 스타일을 통일하고 최종 문서 구조로 합성.
5. **Quality Auditor**: 결과물이 사용자 요구 사항과 ARC 표준을 준수하는지 최종 레드팀 활동 수행.

## 🤝 Human Interrupt (사용자 개입)
- 감독관(Supervisor)은 모호한 상황이나 작업 비용이 큰 경우, 작업을 멈추고 사용자(대장)에게 직접 결재를 요청합니다.
