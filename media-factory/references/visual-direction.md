# Media Factory: Visual Direction & Generation

고품질 AI 이미지 생성을 위한 프롬프트 공학 및 심미안(Aesthetic) 가이드라인입니다.

## 🎨 Visual Direction
- **Aesthetic Quality**: 기본적으로 "Holy Aesthetic" (장엄함, 따뜻함, 전문성)을 지향합니다. 유치하거나 저품질의 일러스트 스타일은 피하십시오.
- **Aspect Ratio**: 
    - YouTube/Video 목적: **Landscape (16:9)** 필수.
    - Social Media 목적: Square (1:1) 또는 Portrait (9:16).
- **Core Fragments**: 프롬프트에 반드시 포함할 고품질 키워드:
    - `Cinematic`, `Photorealistic`, `8k resolution`, `Dramatic lighting`, `Detailed texture`, `Deep shadows`.

## 🛠️ Image Generation Tool
`generate_image` 기능을 사용하며, 생성된 이미지는 `Artifact`로 저장됩니다. 결과물을 최종 납품할 때 사용자의 프로젝트 폴더로 이동 처리하십시오.
