# Gotchas

## 1. 완전 agentic runtime으로 오해하지 말 것

이 프로젝트는 하이브리드 구조다. 에이전트는 오케스트레이션을 보조하지만, 실행기는 기존 파이프라인이다.

## 2. README를 에이전트 지침으로 그대로 쓰지 말 것

`README.md`는 사람용이다. 에이전트는 `GEMINI.md`를 우선 참조해야 한다.

## 3. 대화형 테마 선택

`generate`는 테마가 없으면 사용자 입력을 요구한다. 자동화나 배치 작업에서는 `--design`을 주는 편이 안전하다.

## 4. 시네마틱 이미지 품질

- 텍스트가 섞인 배경 이미지는 실패다.
- 배경은 title card나 포스터처럼 보이면 안 된다.
- 기존 `img_*.jpg`가 있어도 규칙 위반이면 재생성해야 한다.

## 5. 실패 지점 분리

- `generate` 실패: 프롬프트/파싱/슬라이드 생성 문제
- `tts` 실패: API 호출 또는 청킹 문제
- `assemble` 실패: 입력 파일 누락 또는 FFmpeg 세그먼트 문제

전체를 무조건 다시 돌리지 말고, 먼저 깨진 단계를 특정한다.
