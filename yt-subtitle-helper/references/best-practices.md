# YouTube Subtitle Helper: Best Practices & Gotchas

본 문서는 자막 교정 및 API 일괄 업로드 진행 시 발생할 수 있는 주요 예외 상황과 모범 사례를 다룹니다.

---

## 1. 시간 코드 및 구조 무결성 검증 (Timecode Verification)
LLM을 통해 자막을 교정/번역할 때 가끔 시간 코드라인이 누락되거나 합쳐지는 현상(Hallucination)이 발생할 수 있습니다.
* **검증 필수 조건**:
  * 원본 자막 파일의 총 라인(또는 블록) 수와 번역된 자막 파일의 블록 수가 정확히 일치하는지 확인합니다.
  * `00:00:00,000 --> 00:00:00,000` 형식의 정규표현식 패턴 개수가 원본과 번역본에서 동일한지 카운트합니다.
  * 만약 일치하지 않는다면 번역/교정이 누락된 것이므로, LLM에 해당 어긋난 구간만 재시도(Refine)하도록 요청합니다.

## 2. 유튜브 API 할당량 관리 (Quota Management)
* 유튜브 API의 자막 업로드 작업은 1회당 **400 유닛**의 막대한 쿼터를 소모합니다.
* 일일 기본 한도(10,000)는 다국어 자막 배치 몇 번에 쉽게 도달하므로 다음 조치를 준비합니다:
  * **할당량 소진 오류 감지**: API 호출 결과 `quotaExceeded` 에러가 감지되면, 업로드 단계를 일시 중단하고 로컬 파일(`*.srt`)로 안전하게 보관한 뒤 사용자에게 보고합니다.
  * **OAuth 동의 상태 점검**: 로컬 `token.json`이 만료된 경우 `cli.py`에서 자동으로 refresh를 시도하지만, 구글 콘솔의 테스트 사용자가 `만료(Expired)` 상태이거나 비밀번호가 변경된 경우 재로그인을 직접 안내해야 합니다.

## 3. 유튜브 지원 언어 코드 규격 (Language Codes)
유튜브는 BCP-47 표준 언어 코드를 기대합니다. 맞지 않는 언어 코드를 입력하면 API 에러가 발생합니다.
* **주요 지원 언어 코드**:
  * 한국어: `ko`
  * 영어: `en`
  * 일본어: `ja`
  * 중국어(간체): `zh-Hans`
  * 중국어(번체): `zh-Hant`
  * 독일어: `de`
  * 프랑스어: `fr`

## 4. 보안 및 임시 파일 정리 (Hygiene)
* 자막 처리에 사용된 임시 다운로드 파일이나 원본 비정제 자막은 작업이 끝난 후 반드시 삭제하여 사령부 볼트 및 작업 디렉토리가 지저분해지지 않도록 청소(Clean up)합니다.
* `client_secrets.json`과 `token.json`은 개인 유튜브 채널 통제권이 들어 있으므로 Git 등 원격 저장소에 절대 Push되지 않도록 `.gitignore`에 반드시 추가되어 있어야 합니다.
