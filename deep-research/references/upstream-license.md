# 원본과 라이선스

이 스킬은 다음 공개 프로젝트의 연구 절차, 상태 관리 개념, Claim Ledger 검증 방식을 바탕으로 범용 환경에 맞게 다시 설계했다.

- 프로젝트: `fivetaku/insane-research`
- 원본 URL: https://github.com/fivetaku/insane-research
- 원본 라이선스: MIT
- 범용판 변경: Claude Code 전용 플러그인·도구·권한·홍보 설정 제거, 능력 기반 오케스트레이션 추가, 로컬 스킬 표준에 맞춘 점진적 공개 구조 적용
