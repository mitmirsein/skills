# 🪤 아카이빙 함정 및 마크다운 정제 가이드 (Gotchas)

웹페이지에서 마크다운을 추출할 때 에이전트가 흔히 범하는 실수와 이를 회피하기 위한 규칙들입니다.

## 1. 노이즈(Noise) 제거
`read_url_content`는 종종 헤더 메뉴, 내비게이션 바, 사이드바, 푸터, 쿠키 동의 배너, 이메일 구독 팝업 등을 포함하여 텍스트를 추출합니다.
- **Rule 1**: 본문(Main content) 시작 전후에 위치하는 명백한 UI 텍스트(예: "Login", "Sign Up", "Home > About > Contact", "Privacy Policy")는 삭제합니다.
- **Rule 2**: 반복되는 광고 문구나 스폰서 링크 블록은 내용 정제 시 필터링하여 순수한 텍스트만 남깁니다.

## 2. 마크다운 깨짐 및 포맷 오류
- **Rule 3**: 링크(`[text](url)`)가 손상되었거나, 상대 경로(`/about`)로 되어 있어 로컬 환경에서 클릭 시 오류가 날 경우 가능한 한 원본 절대 경로(Absolute URL)로 복원합니다.
- **Rule 4**: 여러 줄로 깨진 표(Table)는 가급적 원래의 마크다운 테이블 규격(`| column | column |`)으로 재구성합니다.
- **Rule 5**: 이미지는 `![alt](url)` 형식으로 남기되, 너무 많은 아이콘이나 1x1 픽셀 추적 이미지는 제거합니다.

## 3. 메타데이터 (Frontmatter) 구문 오류
- **Rule 6**: Frontmatter 내부의 콜론(`:`) 뒤에 오는 문자열 값은 이스케이프 오류를 방지하기 위해 가급적 쌍따옴표(`""`)로 묶어줍니다. (예: `title: "해리포터: 마법사의 돌"`)
- **Rule 7**: 태그 배열 작성 시 하이픈과 공백(`  - tag_name`)의 들여쓰기를 엄격히 맞춥니다.

## 4. 멀티미디어 및 플랫폼 특화 로직
- 긴 문서를 한 번에 클리핑할 경우, 문서가 잘리지 않았는지 확인합니다.
- **YouTube 링크**: `read_url_content`만으로는 영상 내용을 알 수 없으므로, URL이 유튜브인 경우 터미널에서 `yt-dlp` 등을 통해 자막(Transcript)을 직접 추출하여 클리핑 본문에 포함시켜야 합니다.
